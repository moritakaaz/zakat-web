# AGENTS.md

Dokumen ini berisi aturan penulisan kode dan dokumentasi untuk semua agen yang bekerja pada proyek Sistem Pengelolaan Zakat Berbasis Web pada Yayasan Pendidikan Al-Quran Al-Fawwaz Jakarta Utara.

## Aturan Penulisan

1. Kode ditulis dalam bahasa Inggris
2. Dilarang menggunakan format yang terlihat seperti AI slop seperti em dash, titik dua, dan simbol lainnya
3. Jangan menggunakan komentar pada kode terlalu banyak karena akan menimbulkan kebingungan pada suatu hal yang mudah dipahami tanpa harus membaca komentar pada kode
4. Jangan gunakan format komentar pada kode seperti garis sama dengan berulang dan sejenisnya. Gunakan pemformatan sederhana. Untuk satu baris gunakan // . Untuk banyak baris gunakan /* isi komentar */
5. Gunakan bahasa Indonesia pada dokumentasi

## Catatan Tambahan

- Nama variabel, fungsi, dan kelas ditulis dalam bahasa Inggris
- Nama file dan folder ditulis dalam bahasa Inggris
- Dokumentasi, README, PRD, dan penjelasan fitur ditulis dalam bahasa Indonesia
- Komentar hanya ditulis jika logika kode sulit dipahami tanpa penjelasan tambahan
- Ikuti aturan ini pada setiap file kode dan dokumen yang dibuat atau diubah
